Configure uploads

Use Collect into above to change this Mac’s destination. Cloud sign-in for viewing alone does not enable uploads. Advanced CLI configuration is also available.

kikimimi login --org your-workspace

For S3:

kikimimi sink add s3 s3://your-bucket/prefix --profile your-profile

New uploads use the configured destination. Selecting a viewing connection does not move or upload existing history.
